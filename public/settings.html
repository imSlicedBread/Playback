SOOP / INDEPENDENT ADMIN CHAT

Use login IDs, not nicknames. Configure your own SOOP application with approved broad_access_chatinfo scope and redirect http://127.0.0.1:4180/callback. Set SOOP_CLIENT_ID and SOOP_CLIENT_SECRET in Playback's launch environment, then run npm run connect:soop and follow its local link. Restart Playback after changing launch credentials.

SOOP must be live and authorized for the broadcaster ID above. The reader follows the official SDK protocol used by fStream; it needs live acceptance testing in Playback. Tokens stay in the local data folder. No fKey account connection or chat replies are used.

CHAT ADMIN WHITELIST

Separate up to 100 usernames with commas or newlines. Capitalization and a leading @ are ignored. Save Settings to apply access changes. An empty list disables chat admin commands.

Only listed usernames qualify, including broadcasters and moderators. Access follows the username if it changes ownership. Manage access here; chat commands cannot change the whitelist.

Allow 2 seconds between admin commands; the station accepts at most 30 per minute. Results appear below. No replies are sent to Twitch chat.

ADMIN COMMANDS

!pause / !resume
Pause or resume playback
!forceskip
Skip immediately, including during voting. !skip remains a viewer skip vote.
!previous / !replay
Play the previous video or restart the current video
!seek SECONDS
Jump to an absolute position
!volume 0-100
Set volume while preserving mute; zero also mutes
!mute / !unmute
Mute or unmute; unmuting at zero restores volume to 50
!add URL
Add directly to Upcoming
!playnext URL
Add to Play Next
!playnow URL
Play immediately; resume the interrupted video next

Commands ignore capitalization. Video commands also accept a video ID and an optional | Display title.
