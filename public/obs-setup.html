OBS Plugin Setup_

Play YouTube in OBS with your signed-in account and the Playback queue controls.

SET UP IN OBS

  1. Close OBS, run fKey-Playback-OBS-Plugin-Setup-0.1.4.exe, approve the Windows administrator prompt, and click Install / Update. Use Browse if OBS is in a custom folder, then open OBS from your usual shortcut. The installer targets Windows x64 and OBS 32.2.2 / Qt 6.11.1.
  2. Open Docks → fKey Playback. Set Station port to 4177.
  3. Choose Sign in / manage YouTube account and complete sign-in in the output window. Use the account entitled to watch the video; Chrome's login is separate.
  4. Choose Start queue / retry, then Add Playback source to current scene. Plugin 0.1.1 or newer adds the video and transparent overlay, sizes them to the canvas, and places the overlay above the video. Clicking again repairs missing sources without duplicates.
  5. Check the Playback YouTube Output audio meter and stream/recording track. Keep audio monitoring off to avoid duplicate sound.
  6. Optional: enable Start this output when OBS opens. Playback also needs to be running; use the existing Windows startup installer if needed.

Choose Output resolution and click Apply for 720p, 1080p, 1440p, 4K, or the current OBS canvas size. Your choice is saved. This sets the OBS render size; YouTube stream quality remains automatic.

Lock output (size + controls) is on when playback starts. It fixes the output size and blocks accidental interaction. Uncheck it before manually handling a YouTube prompt, then recheck it afterward. Sign-in mode unlocks it automatically.

The output window must stay open. In plugin 0.1.1 or newer, minimize parks it out of view while OBS continues capturing it. Choose Show output window to bring it back for interaction.

Disable the old /player Browser Source when using the plugin. Only one output can control the queue. The sidebar's Overlay Preview shows titles and votes without starting another player.

YOUTUBE ACCESS

Members-only video playback was verified by the user on October 20, 2026, using a signed-in, entitled YouTube account in the native OBS plugin. This confirms playback for the tested account and video; other accounts still need their own membership access. YouTube sign-in, age/content confirmations and access dialogs require manual interaction.

For the older Browser Source workflow, use the Browser Source sign-in guide. YouTube embedding restrictions still apply.
