OBS BROWSER SOURCE / ONE-TIME SETUP

YouTube sign-in in OBS_

Sign in inside OBS so YouTube can use that OBS browser session. Signing in to Chrome or to the Playback dashboard is separate.

  1. In the Playback dashboard, open Settings → Playback, enable Use the YouTube account signed in inside OBS, and click Save Settings.
  2. In OBS, use your Playback Browser Source. Temporarily set its URL to https://www.youtube.com/. Click Interact, then Sign in and complete the Google login yourself. If you loaded this setup page in that OBS source, the button below opens YouTube in the same source.
  3. After signing in, change that same source's URL back to the Playback player URL below. Keep Shutdown source when not visible and Refresh browser when scene becomes active disabled.
  4. Test an account-restricted video and restart OBS once to check login persistence. This setup cannot confirm which Google account is signed in. Members-only playback remains unverified and YouTube can still deny embedding or request login again. Age-restricted videos may require the normal YouTube watch page even when signed in; account mode cannot override that restriction.
